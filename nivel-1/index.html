O QUE É A INTERNET?

Módulo 1 de 4

🌍 A Rede Global

A Internet é uma rede global de computadores interligados. Imagina milhões de computadores em todo o mundo, todos conectados entre si, partilhando informação.

Quando acedes a um website, o teu computador comunica com outro computador (servidor) que pode estar do outro lado do mundo!

💡 ANALOGIA

Pensa na Internet como um sistema de correios ultra-rápido. Quando envias uma carta (dados), ela viaja por vários pontos de distribuição (routers) até chegar ao destino. A diferença? Em vez de dias, demora milissegundos!

🔗 Como Funciona?

Os dados viajam em pequenos "pacotes" através de cabos (fibra ótica, cobre) e ondas (Wi-Fi, 4G/5G). Cada pacote sabe para onde ir graças a endereços especiais.

# Exemplo: Quando acedes ao google.com
1. O teu PC envia um pedido
2. O pedido viaja pela rede
3. Chega ao servidor do Google
4. O servidor responde com a página
5. A página aparece no teu ecrã
⏱️ Tempo total: ~50 milissegundos

ENDEREÇO IP

Módulo 2 de 4

📍 A Morada Digital

Cada dispositivo na Internet tem um endereço IP (Internet Protocol). É como a morada da tua casa, mas para computadores!

Sem um IP, os dados não saberiam para onde ir.

🔢 Formato do IPv4

O formato mais comum é o IPv4, composto por 4 números separados por pontos. Cada número vai de 0 a 255.

# Exemplos de endereços IP
192.168.1.1
→ IP típico de um router doméstico
8.8.8.8
→ Servidor DNS do Google
142.250.200.46
→ Um IP do Google.com

💡 ANALOGIA

O IP é como o número da tua casa. Se alguém te quer enviar uma encomenda, precisa de saber a morada. Na Internet, se um servidor te quer enviar dados, precisa do teu IP!

🔍 DESCOBRE O TEU IP PÚBLICO

O teu IP público é como os outros te veem na Internet:

🏠 IP Público vs IP Privado

IP Público: O endereço que te identifica na Internet (visível para o mundo).

IP Privado: O endereço dentro da tua rede local (só visível em casa). Começa geralmente por 192.168.x.x ou 10.x.x.x

DNS - DOMAIN NAME SYSTEM

Módulo 3 de 4

📚 A Lista Telefónica da Internet

Lembras-te que cada site tem um IP? Imagina ter de decorar 142.250.200.46 em vez de google.com!

O DNS (Domain Name System) traduz nomes fáceis de lembrar em endereços IP.

💡 ANALOGIA

O DNS é como a agenda de contactos do teu telemóvel. Em vez de decorares o número 912345678, guardas como "Mãe". Quando ligas à "Mãe", o telemóvel sabe qual é o número. O DNS faz o mesmo: tu escreves "google.com" e ele sabe que é 142.250.200.46!

⚡ Como Funciona?

Tu escreves: google.com
↓
Passo 1: O teu PC pergunta ao servidor DNS
"Qual é o IP de google.com?"
↓
Passo 2: O DNS responde
"É 142.250.200.46!"
↓
Passo 3: O teu PC liga-se a esse IP

🛡️ Porque é Importante para Segurança?

Atacantes podem manipular o DNS para te redirecionar para sites falsos! Isso chama-se DNS Spoofing. Por isso, é crucial usar servidores DNS confiáveis.

# Servidores DNS populares e seguros:
8.8.8.8
→ Google DNS
1.1.1.1
→ Cloudflare DNS (muito rápido!)

PORTAS DE REDE

Módulo 4 de 4

🚪 As Entradas dos Serviços

Um computador pode ter muitos serviços a correr ao mesmo tempo: web, email, jogos... Como é que os dados sabem para qual serviço ir?

As portas são como portas de um edifício. Cada serviço "vive" numa porta específica!

💡 ANALOGIA

Imagina um prédio de escritórios (o servidor). Cada empresa (serviço) tem o seu próprio andar (porta). Se queres ir ao dentista (web), vais ao 4º andar (porta 80). Se queres o advogado (email), vais ao 2º andar (porta 25).

📋 Portas Importantes para SOC

# Portas que TENS de conhecer:
Porta 80
→ HTTP (websites sem encriptação)
Porta 443
→ HTTPS (websites seguros 🔒)
Porta 22
→ SSH (acesso remoto seguro)
Porta 21
→ FTP (transferência de ficheiros)
Porta 25
→ SMTP (envio de email)
Porta 53
→ DNS (tradução de domínios)
Porta 3389
→ RDP (Remote Desktop Windows)

🛡️ Portas e Segurança

Portas abertas desnecessariamente são um risco! Atacantes procuram portas abertas para explorar. Um analista SOC monitoriza que portas estão abertas e deteta atividade suspeita.

# Alerta típico num SOC:
[AVISO] Port scan detetado de 185.234.x.x
→ Tentativas em portas: 22, 23, 80, 443, 3389
→ Possível reconhecimento por atacante!
